# Val-regal — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Afegir el flux complet de compra de val-regal a `/regala/`: formulari inline, pagament via PayPal Smart Buttons, POST a Make.com, missatge d'èxit — sense Tally, sense redireccionaments.

**Architecture:** El quiz existent (main.js) recomana tallers i renderitza un botó `<button class="gift-regala-btn">` per cada un. Fer clic a aquest botó mostra el formulari inline (`#gift-form-wrap`) amb les dades del taller pre-omplertes. Quan el formulari és vàlid, apareix el PayPal Smart Button (SDK JS). En confirmar el pagament, el callback `onApprove` fa POST a Make.com amb totes les dades i mostra l'estat d'èxit.

**Tech Stack:** Hugo (params), Vanilla JS (inline en gift.html), PayPal JS SDK v2, Make.com webhook (extern), CSS custom properties

Afegeix JUST BEFORE del `{{ end }}` final, AFTER el script del SDK:

```html
  <script>
  (function () {
    var formWrap    = document.getElementById('gift-form-wrap');
    var successDiv  = document.getElementById('gift-success');
    var quizWrap    = document.querySelector('.gift-quiz-wrap');
    if (!formWrap) return;

    var webhookUrl       = formWrap.dataset.webhook || '';
    var paypalRendered   = false;

    /* ── Mostrar formulari en clicar qualsevol .gift-regala-btn ── */
    document.addEventListener('click', function (e) {
      var btn = e.target.closest('.gift-regala-btn');
      if (!btn) return;

      document.getElementById('gift-taller').value         = btn.dataset.title || '';
      document.getElementById('gift-import').value         = btn.dataset.preu  || '';
      document.getElementById('gift-form-subtitle').textContent =
        btn.dataset.title ? 'Val per a: ' + btn.dataset.title : 'Val d\'import lliure';

      /* Reset estat formulari */
      document.getElementById('gift-form-error').setAttribute('hidden', '');
      document.getElementById('gift-paypal-wrap').setAttribute('hidden', '');
      document.getElementById('gift-form-submit').removeAttribute('hidden');
      document.getElementById('gift-paypal-error').setAttribute('hidden', '');

      quizWrap  && quizWrap.setAttribute('hidden', '');
      formWrap.removeAttribute('hidden');
      formWrap.scrollIntoView({ behavior: 'smooth', block: 'start' });
    });

    /* ── Tornar a les recomanacions ── */
    document.getElementById('gift-form-back').addEventListener('click', function () {
      formWrap.setAttribute('hidden', '');
      quizWrap && quizWrap.removeAttribute('hidden');
    });

    /* ── Validar i mostrar PayPal ── */
    document.getElementById('gift-form-submit').addEventListener('click', function () {
      var errorEl  = document.getElementById('gift-form-error');
      var perA     = document.getElementById('gift-per-a').value.trim();
      var de       = document.getElementById('gift-de').value.trim();
      var email    = document.getElementById('gift-email').value.trim();
      var importV  = parseFloat(document.getElementById('gift-import').value);
      var emailRe  = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

      if (!perA || !de || !email || !importV) {
        errorEl.textContent = 'Omple tots els camps obligatoris.';
        errorEl.removeAttribute('hidden');
        return;
      }
      if (!emailRe.test(email)) {
        errorEl.textContent = 'L\'adreça de correu no és vàlida.';
        errorEl.removeAttribute('hidden');
        return;
      }
      if (importV < 20) {
        errorEl.textContent = 'L\'import mínim és 20€.';
        errorEl.removeAttribute('hidden');
        return;
      }

      errorEl.setAttribute('hidden', '');
      this.setAttribute('hidden', '');
      document.getElementById('gift-paypal-wrap').removeAttribute('hidden');
      if (!paypalRendered) renderPayPal();
    });

    /* ── Inicialitzar PayPal Smart Buttons ── */
    function renderPayPal() {
      if (!window.paypal) {
        document.getElementById('gift-paypal-error').removeAttribute('hidden');
        return;
      }
      paypalRendered = true;

      paypal.Buttons({
        style: { layout: 'vertical', color: 'gold', shape: 'rect', label: 'pay' },

        createOrder: function (data, actions) {
          var importV   = parseFloat(document.getElementById('gift-import').value) || 0;
          var tallerNom = document.getElementById('gift-taller').value || 'Val regal Llumàtics';
          return actions.order.create({
            purchase_units: [{
              description: 'Val regal Llumàtics — ' + tallerNom,
              amount: { value: importV.toFixed(2), currency_code: 'EUR' }
            }]
          });
        },

        onApprove: function (data, actions) {
          return actions.order.capture().then(function (details) {
            var payload = {
              per_a:              document.getElementById('gift-per-a').value.trim(),
              de:                 document.getElementById('gift-de').value.trim(),
              missatge:           document.getElementById('gift-missatge').value.trim(),
              email:              document.getElementById('gift-email').value.trim(),
              import:             parseFloat(document.getElementById('gift-import').value),
              taller_nom:         document.getElementById('gift-taller').value.trim(),
              paypal_order_id:    details.id,
              paypal_payer_email: details.payer.email_address,
              data:               new Date().toISOString().split('T')[0]
            };

            var successEmail = payload.email;
            var req = webhookUrl
              ? fetch(webhookUrl, {
                  method: 'POST',
                  headers: { 'Content-Type': 'application/json' },
                  body: JSON.stringify(payload)
                })
              : Promise.resolve();

            req.catch(function () {}).then(function () {
              showSuccess(successEmail);
            });
          });
        },

        onError: function (err) {
          console.error('PayPal error:', err);
          document.getElementById('gift-paypal-error').removeAttribute('hidden');
        }
      }).render('#paypal-button-container');
    }

    /* ── Mostrar pantalla d'èxit ── */
    function showSuccess(email) {
      formWrap.setAttribute('hidden', '');
      successDiv.removeAttribute('hidden');
      document.getElementById('gift-success-email').textContent = email;
      successDiv.scrollIntoView({ behavior: 'smooth', block: 'start' });
    }

  }());
  </script>
```

## Notes d'implementació

- **PayPal SDK locale:** `ca_ES` per textos en català al botó de PayPal. Canviar a `es_ES` si es prefereix castellà.
- **Sense PayPal SDK:** si `paypalClientID` és buit, el script del SDK NO es carrega. El formulari apareixerà però `#gift-paypal-wrap` estarà buit i `window.paypal` serà `undefined` → l'error de PayPal es mostrarà. Acceptable en local sense config.
- **Seguretat del webhook:** Make.com pot configurar un secret token per validar que el POST ve del lloc legítim. Per ara, l'URL del webhook és suficient per a volums baixos.
- **El missatge és opcional:** si el camp `missatge` és buit, Make.com ha d'ometre el bloc de quotes al PDF (condicional a Make.com, no al JS).
- **Import mínim 20€:** PayPal pot rebutjar ordres molt petites amb errors de divisa. 20€ és un límit segur.
